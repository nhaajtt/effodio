Describe it. Find it.

Glint searches the files on your computer by what's in them: a photo by what it shows, a PDF by what a page says, a recording or a video by the moment. Everything runs on your PC.

PS> powershell -c "irm https://glint.nhaajt.com/install.ps1 | iex"

One search for every kind of file

By meaning

Type "a dog on the beach" and get the photo, with no tags and no file names to remember. It works in more than 100 languages.

To the page, to the second

A result opens where it matched: the PDF at page 3, the video at the moment the zebra walks in. A strip shows every matching moment.

Text inside pictures

Windows reads the words in screenshots and scans, so an error code or a booking number is found exactly as written.

Search by example

Drop or paste a picture, or press Tab on a result, and Glint finds what looks or reads like it.

Filters you type

kind:video in:Downloads ext:pdf after:30d "exact words" -word

Accents optional

"hoa don tien dien" finds "Hóa đơn tiền điện tháng 10". A map of everything by meaning and a list of near-duplicates come with it.

Nothing you index leaves your computer

The model that understands your files is a small one that runs on your own PC. Glint goes online once, to download it (865 MB). After that it works offline. No account, no telemetry.

  • Only reads your files. Never changes, moves or uploads them.
  • Skips keys, certificates, password files, hidden and system folders.
  • In a code project it reads only screenshots.
  • Installs for your user only. No administrator rights.

Two ways to install

One line in PowerShell

Downloads the installer from this site, checks its SHA-256, and installs it quietly. Run the same line again to update.

Read the script before you run it

The installer

The installer isn't signed yet, so Windows asks before running it: choose More info, then Run anyway.

Glint___VERSION___x64-setup.exe

SHA-256 of the installer: __SHA256__

Recordings and videos need FFmpeg: winget install Gyan.FFmpeg. Everything else works without it.
